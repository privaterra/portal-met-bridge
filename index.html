Recording

Final weight

The profile's final_weight is read from the machine's own record of the shot (so two profiles sharing a name cannot be mixed up); until the record is attached it comes from the loaded profile's id. The scale option misses nothing that happened after the pump stopped as long as the settle window covers the drips. With the typed option nothing stands in: a shot shows ? g until you enter the weight (Enter final weight on the Shots tab, ? g in History, or History → Edit). A weight you type always wins, whichever option is chosen; the choice applies to every shot, including earlier ones.

Saving

Every shot is written to this browser's database while it is being recorded (a checkpoint every two seconds) and finalised when the pump stops, so a closed tab or a crash loses at most the last two seconds. The machine's own record is attached afterwards, and any shot still missing it is completed the next time the machine connects.

The save folder is chosen under Logging and debug → Where to save; files land in portal-met-bridge/shots/.

Estimates

Which shots an estimate may borrow from (this bean, same roaster, same roast level, all) is chosen on the Shots view next to the estimate.

About you and your gear

Saved reviews

The default for the Download buttons on the Analysis tab; each button also has its own format picker. All three carry the same header (title, date, provider and model, the shots, your taste note and question) and the same sections.

The key is kept in this browser's database on this computer and sent only to the provider you chose, with the shot digest, the brewed profile and your notes. It is left out of settings exports and backups. Each review costs a few cents of API usage; the README explains how to create a key with a spending limit.

Logging and debug

Where to save

By default the log lives in this page (last 5,000 lines) and you download it. Pick a folder on this Mac and the log is appended to portal-met-bridge/logs/<date>.log there as it happens; exports and backups can be saved there too. Chrome asks you to re-allow the folder after a restart.

Erases everything this app has stored in this browser — shots and their samples, refractometer readings, the bean library, saved AI reviews, all settings including API keys, the debug log and the Portal pairing — and, if you choose, the files it wrote in your save folder.
