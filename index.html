Portal

Close the Belka app first; the Portal accepts one connection at a time. Needs Chrome or Edge.

Connection check
  1. Page is secure (localhost)
  2. Web Bluetooth available
  3. Bluetooth adapter on and allowed for Chrome
  4. Portal chosen
  5. GATT connected
  6. Service 0x7400 found
  7. Measurement 0x7410 found
  8. Command 0x7420 found
  9. Notifications started
  10. 13-byte packets arriving

On macOS, Chrome needs Bluetooth permission: System Settings → Privacy & Security → Bluetooth → Google Chrome.

This coffee

Picking a previous bean fills in its roaster, roast level, process and origin. Calibration is kept per bean name, so keep the name stable while you work through a bag.

    Machine

    Estimates

    Which shots an estimate may borrow from (this bean, same roaster, same roast level, all) is chosen on the Shots view next to the estimate.

    Backup and restore

    Settings only

    Machine address, recording, estimate and logging options, and the current coffee. Shots and beans are not included.

    Everything

    All shots with their samples, refractometer readings, the bean library and the settings. Restoring merges by shot id; nothing is deleted.

    Files go to Chrome's download folder unless a save folder is set below.

    Logging and debug

    Where to save

    By default the log lives in this page (last 5,000 lines) and you download it. Pick a folder on this Mac and the log is appended to portal-met-bridge/logs/<date>.log there as it happens; exports and backups can be saved there too. Chrome asks you to re-allow the folder after a restart.
